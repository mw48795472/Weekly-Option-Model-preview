# 종목별 자료에서 지금 분석할 것

기준 자료는 2026-10-11에 확보한 공개 NH 지수 종목 마스터다. 이름 규칙으로 선정한 지수 위클리 후보이며, 특정 개별주식 위클리 상장 여부를 판정하는 자료는 아니다. 파일 확보일은 시장 관측시각이 아니다.

## 파일 선택

`weekly_contracts.csv`는 고유 코드 766개를 한 행씩 담는다. 같은 코드의 세션별 식별 속성이 일치할 때만 통합하며, 충돌 시 공란과 `identity_conflict_fields`로 표시한다. 원문 전체는 `weekly_contract_sessions.csv`의 1,258행에 남긴다. 키는 `(cme_tp, series)`이며 중복 키는 생성기를 중단시킨다.

`products/`에는 4상품군별 통합본, ZIP의 `symbols/`에는 종목코드별 파일 766개가 있다. 개별 파일은 주간·야간 관측에 따라 1~2행이다. 모든 CSV의 한글은 UTF-8 BOM으로 저장하며 원코드 앞자리 0은 유지한다. Excel 자동 형변환을 피하려면 코드 열을 텍스트로 가져온다.

`variable_dictionary.csv`는 원변수 26개, 진단·상태 12개, 미확보 관측/연구 변수 23개를 다룬다. 범위와 관측 수는 세션 원장 기준이며 고유 계약 수와 혼동하지 않는다. 통합본의 `day_`/`night_` 접두 열은 사전의 해당 원변수다. `sessions`는 세션 목록, `session_rows`는 세션 행 수, `identity_conflict_fields`는 통합할 수 없는 식별 속성 목록이다. 상한·하한 가격 원값을 bid/ask나 현재가로 바꾸지 않는다.

## 실제 발견과 의미

| 점검 | 현재 결과 | 분석에 반영할 점 |
|---|---|---|
| 주간/야간 | 492/766행, 야간에만 274계약 | 주간 데이터만 쓰면 전체 후보의 35.8%가 제외됨 |
| 콜풋 짝 | 모든 1,258행에 같은 세션·상품·만기·행사가의 유일한 반대 유형 코드 연결 | 체인 비교의 구조는 준비됨. 가격 패리티·OI PCR은 아직 계산 불가 |
| 식별 속성 | 공통 492계약의 선택한 식별 속성 충돌 0 | 원코드 기준 연결 가능. 시세 동시성은 별도 확인 |
| 세션별 원값 | 공통 492계약 모두 잔존일수 등 차이 존재 | 첫 행을 선택하는 방식으로 통합 금지 |
| 만기일−rem_cnt | 주간 10-07, 야간 10-11 | 공급자 공표일로 단정하지 않고 갱신·잔존일 규칙 확인 |
| 행사가 간격 | 각 상품·만기·세션 그룹에서 WKI/WKM 2.5, WQI/WQM 25 | 관측된 간격. 공식 상장 간격·호가 틱이나 호가 유동성 아님 |
| 비어 있는 원필드 | class 전부 공란 | 범주형 피처로 임의 대체하지 않음 |

예를 들어 `B09FG952`는 행사가 952.50, 2026-10-15 만기인 코스피 위클리 콜 후보다. 원문 rem_cnt는 주간 8, 야간 4다. 확보일 10-11 기준으로 계산한 달력 차이는 4일이지만 주간 원문 8일을 4로 고쳐 쓰지 않는다. 반대 콜풋 계약은 같은 세션의 `C09FG952`다.

## 변수 확보 후 분석 순서

1. 계약·세션·타임스탬프와 유효 bid/ask를 맞춘다. 상대 스프레드는 `10000*(ask-bid)/mid`이며 양수이고 뒤집히지 않은 동시 호가에만 적용한다.
2. 기초자산 분봉에서 완결 세션 RV를 만든다. 766개 계약 행을 766개의 독립 RV 시점으로 취급하지 않는다.
3. 실제 잔존시간·상품군·요일을 추가해 H5를 평가한다. 단순 목요일 더미와 상품군 효과를 구분한다.
4. `opint`와 `pd_opint`의 공표시각·롤을 확인한 뒤 H6를 평가한다. 전기 OI가 0이면 변화율은 결측이다. 다음 5일 RV는 t+1부터 계산하고 미래가 부족한 마지막 구간은 결측으로 둔다.
5. 검증된 IV·Greeks와 같은 시각의 선도/현물로 머니니스·스큐·민감도를 추가한다. 현재 마스터 행사가만으로 ATM을 고르지 않는다.

현재 확보가 안 된 변수는 빈칸이며 0이나 모의 관측값으로 채우지 않았다. PoC의 σ=25%, OI=10,000/12,000, 합성 RV 등은 `poc_assumptions.csv`에 따로 두었다. API 응답 필드 존재 여부는 보존된 `data/catalog/catalog.json`의 `/trade/v1/domestic/price` 명세와 대조했다. 현재 응답 값이나 예측 성능을 확인했다는 의미는 아니다.
