# 개별주식 H5·H6 사전 분석 규칙

2026-10-12: 결과 회귀 실행 전에 고정. 기존 7개 표준 주식옵션 계열(CA, CC, CD, CZ, DH, DV, DX), TWSE 1303·2303·2330·2603·2317·2454·3231을 대상으로 한다. 선택 당시 명부에 기초한 표본이며 전체 주식 시장을 대표하지 않는다.

- 주가: 2025-01-01–2026-10-08의 공식 일별 OHLC. 옵션은 최초 위클리 상장 월부터 월별 요청. 역사 catalog의 조정계약 별칭을 함께 보존하고 서로 다른 계약 ID를 강제로 이어 붙이지 않는다. OI는 계약 수이며 조정주식수/명목금액이 아니다.
- TAIFEX의 실제 최종결제일과 원장 예정 만기를 대사한다. 달력은 사후 확정본이며 당시 공지 판본이 아니다. 기초주가 전체 거래일을 유지하며 상장 전 옵션 OI는 결측이다. 상장 후 누락 응답을 OI 0으로 채우지 않는다.
- 일별 Parkinson 분산이 주 결과. TWSE X(비교불가)·주석·거래정지/결측·가격이 전일종가와 공표 증감으로 일치하지 않는 날짜를 점검한다. 종가수익률 제곱 민감도는 해당 날짜와 누락 구간의 수익률을 결측 처리한다. 수정주가/배당재투자 총수익률이라고 부르지 않는다.
- H5 주 모형: 종목별 log(Parkinson), 위클리 만기 당일/전/후·월물만기·상장 이후·요일·자기 과거 1/5/22일 분산·전일 시장 분산 통제. 장기 주가 표본의 조건부 연관성이며 도입의 인과효과가 아니다. HAC 5/20, 상장 후만 사용한 rank 검사, 요일×상장후 통제와 비교불가일 제외 민감도. rank 부족이면 해당 모형의 계수는 발표하지 않는다. 당일/전/후 × 7종목의 21개 비교에 Bonferroni 동시구간을 병기한다.
- H6 주 검증: 기존 지수 분석과 동일한 5거래일 동일계약 OI 변화율, 1일 지연. 2일 지연 및 전체 체인 변화율은 민감도. 최소 100개 완결 훈련 라벨, 다음 5거래일 분산 평균, 확장창과 label-end < origin을 유지한다. 종목별·대용치별 모델은 정확히 같은 테스트 날짜로 비교. 30개 미만 테스트는 단기 탐색으로 표시하고 0개면 불가로 표시한다. 결과를 본 뒤 최소 훈련 수를 낮추지 않는다.
- 희소 OI에 대한 사전 지정 보조 검증: log(1+전체 위클리 OI)의 1일·2일 지연을 각각 HAR+만기 달력 기준에 추가. 주 검증의 대체 성공 사례로 합치지 않으며 별도 family/가용 표본을 표시한다. 상장 전 0 생성 금지.
- 주 QLIKE 차이는 추가모형−기준. 5/10/20거래일 이동블록, 2,000회, seed 4879. 빈 테스트 날짜도 전체 거래일 위치에 유지. 주 block=10, 7종목을 고려한 Bonferroni 구간 병기. 종목 행을 독립 표본으로 합치거나 서로 다른 날짜의 점수를 순위화하지 않는다.
- 장중 RV·마감 가격반전·수익성·국내 전이·실시간 운용을 검증했다고 주장하지 않는다. 모델 선택/튜닝·주문·API 키 사용 없음.

구현 명시: 관측 H=L인 날은 가격자료 누락과 별도 집계하되 양의 범위·로그 모형에서는 대용치를 결측 처리한다. 따라서 이후 22일 과거창과 5일 미래창의 가용성이 줄어든다. 이 선택은 가격제한 등으로 범위가 관측되지 않는 날에 0의 잠재 변동성을 가정하지 않기 위한 제한이며, 종가수익률 민감도와 함께 공개한다. 날짜 자체를 삭제하거나 과거창을 압축하지 않는다. 종가 변화 0을 사용하는 지속모형은 QLIKE 계산에 쓰는 바닥값 1e-12를 예측 출력에도 동일하게 적용한다.
