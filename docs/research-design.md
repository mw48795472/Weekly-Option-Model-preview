# NH선물 데이터에 맞춘 위클리옵션 모델 연구 설계

**1차 연구 질문은 실제 만기·OI·유동성 정보가 과거 실현분산만 사용하는 모형보다 다음 거래일의 변동성 위험 예측을 개선하는가이다.** 기존 기획서의 개별주식 위클리 도입 위험·해외 전이 목적을 유지하되, 현재 확인된 자료로는 지수 위클리의 계약 선정과 수집 설계부터 시작한다. 이 문서의 모형과 일정은 제안이며 실증 성과가 아니다.

근거는 [기존 21개 자료 감사](source-audit.md), [49개 API 명세](api-catalog.md), [공개 마스터 분석](../data/analysis/master_summary.json)이다. 현재 개인 키는 설정되지 않았다.

## 공개 자료에서 지금 분석한 내용

[NH 종목 마스터 페이지](https://apidev.futures.co.kr/#/api/info/market-master)에서 국내 3개 파일을 직접 내려받았다. gzip 해제 후 UTF-8, 세미콜론 구분 26필드로 읽었고 모든 행의 필드 수를 검사했다. 문서의 `exp_ym` 명칭은 만기년월이지만 실제 값은 8자리 날짜다. `series`와 `real_Code`를 구분해 보존한다.

| 파일·메뉴 | 전체 행 | 옵션 행 | 고유 series | 위클리 이름 후보 행 | 위클리 고유 series |
|---|---:|---:|---:|---:|---:|
| `fut_opt.mst.gz` / 지수 | 14,532 | 14,380 | 7,789 | 1,258 | 766 |
| `stk_fut_opt.mst.gz` / 주식 | 11,071 | 9,598 | 11,071 | 0 | 0 |
| `idx_fut_opt.mst.gz` / 상품 | 141 | 0 | 96 | 0 | 0 |

위클리 후보는 옵션이면서 한글명에 `위클리` 또는 영문명에 `WEEK`가 있는 행이다. 거래소가 인증한 상품 분류가 아닌 **이름 기반 후보 규칙**이다. 지수 후보는 WKI 410행, WKM 664행, WQI 70행, WQM 114행이며 만기는 2026-10-12/15/19로 관측됐다. 주간 492행, 야간 766행이므로 1,258행을 서로 다른 계약 1,258개로 세지 않는다. `(cme_tp, series)` 중복은 세 파일 모두 0이다. 후보 원장은 [CSV](../data/analysis/weekly_candidates.csv)로 재현한다.

`만기일 - rem_cnt`를 계산한 진단값은 지수 주간·주식·상품 주간에서 2026-10-07, 지수·상품 야간에서 2026-10-11이다. 이는 공급자 공표시각이 아니며 잔존일수 규칙과 휴장·갱신 시점의 영향을 받을 수 있다. 다운로드 날짜만으로 모든 레코드가 같은 시점의 최신 자료라고 간주하면 안 된다. 공식 마스터의 `mrkt_tp` 설명과 일부 주식선물·상품야간 행의 값도 일관되지 않아 단일 숫자만으로 상품군을 재분류하지 않는다.

주식 마스터에서 위클리 이름 후보가 0이라는 결과로 국내 개별주식 위클리의 미상장을 단정할 수 없다. 명칭 규칙·갱신 상태와 KRX의 날짜 있는 공지, 실제 대표 계약 조회를 대조해야 한다. 이번 결과는 **지수 파일럿을 준비할 수 있다는 증거**이고 개별주식 도입 인과효과를 검증할 증거는 아니다.

`domestic/open-interest`는 시장 OI가 아니라 계좌 잔고이므로 H6 수집 경로에 넣지 않는다. 동일 계약의 시장 OI를 비교하고 신규상장·만기 소멸·계약 롤을 표시한다. `ΔOI/OI(t-1)`와 `Δlog(1+OI)`는 서로 다른 피처다. 분모가 0이거나 OI가 누락되면 변화율은 결측으로 둔다. OI×감마는 부호를 알 수 없는 규모 지표일 뿐 딜러의 순롱/순숏을 식별하지 않는다.

분봉 요청은 `dcnt=1`을 명시한다(기본은 5). `req_qty` 기본 300, 최대 9,999; `nxt_key` 기본 99999999와 반환 cursor를 기록한다. 옵션 체인은 `nxt_stkr_pric`으로 연속조회한다. 한 페이지를 전체 체인·전체 역사라고 부르지 않으며, 동일 cursor 반복·중복행·진행 없는 페이지를 중단 조건으로 둔다. 종료 cursor의 실제 표현은 인증 후 확인한다. ## 가설별 범위

가설 번호는 최신 `위클리 옵션 모델 기획서.pdf` p4를 따른다. 인과적 도입효과와 예측 정보의 유용성을 별개 결과로 보고한다.

| 가설 | 이번 설계에서의 상태 | 실증 조건 |
|---|---|---|
| H1 도입→현물 변동성 | 보류 | 실제 도입일·사전 자료·대조군·사전추세, 동시 제도변경 통제 |
| H2 아시아 전이 | 후속 | 국내 단독 대비 해외 정보의 추가 성능, 당시 이용 가능 시각 정렬 |
| H3 커버드콜 수요 | 외부 자료 필요 | 현물 보유·옵션 매도 노출. AUM 증가를 순유입·매도 포지션으로 대체하지 않음 |
| H4 공포·탐욕 국면 | 예측 층화로 유지 | 훈련기간에서 정한 국면, 국면별 표본 수·오차·보정 |
| H5 만기 효과 | 1차 핵심 | 목요일 고정 대신 계약별 실제 잔존시간·요일·동시만기·휴일 통제 |
| H6 OI→다음 주 RV | 1차 조건부 핵심 | OI 가용시각·계약 연결·완성된 미래 라벨·기준모형 대비 추가 정보 |
| H7 수급 집중도 | 후속 | 시변 보유/집중도 자료, 충분한 횡단면. 4종목 고정 상수의 합성 상관은 실증 제외 |
| H8 기관 리밸런싱 | 외부 사건 자료 필요 | 실제 노출 변화와 사건 식별. 순매수 집계만으로 리밸런싱 원인 확정 불가 |
| H9 RFQ→롱/숏 | 원 가설 보류 | RFQ 요청·응답·체결 로그 필요. 장내 호가로 관측할 새 연구는 H9b로 구분 |

H9b는 다음 1/5분의 스프레드 확대·호가 공백·RV 예측으로 정의한다. 미래 스프레드 라벨을 주가 상승/하락 라벨로 부르지 않는다. REV는 만기일 마지막 30분과 다음 거래일 시가·1분·30분의 반전을 측정하는 보조 이벤트 연구다. 차익거래 비중이 없으면 원 자료의 H/L 그룹 검증은 보류한다.

## 1차 모델·라벨·검증 규약

파일럿 주 타깃은 **사전에 고정한 KOSPI200 근월선물의 다음 완결 거래일 장중 실현분산**으로 제안한다. 현물지수 분봉을 정상 확보하면 별도 현물 타깃을 만든다. 선물 RV 결과를 현물 변동성 효과로 해석하지 않는다. 계약 롤일과 야간·장전 수익률은 구분해 기록한다.

`RV(d) = Σ log(P_j/P_(j-1))²`를 동일 세션의 고정 5분 격자에서 계산한다. 1분봉은 집계 기반이며 시세 공백을 무제한 채우지 않는다. 세션 경계와 계약 롤을 넘는 수익률은 장중 합계에서 분리한다. 일별 절대수익률×√252를 RV 대신 사용하지 않는다. RV는 분산, √RV는 변동성이므로 단위와 연율화는 평가표에 명시한다.

의사결정은 사전 정의한 거래일 세션 종료 후, 그때 도착한 정보만 사용하는 시점으로 고정한다. OI의 제공 시각을 알 수 없으면 EOD 신호에 넣기 전에 보수적 지연을 설정하고 민감도를 보고한다. 주 라벨은 다음 1거래일, H6 보조 라벨은 다음 5거래일의 누적 RV다. 5분 평균 등 장중 H9b 라벨과 혼동하지 않는다.

| 비교 순서 | 모델/피처 | 채택 기준 |
|---|---|---|
| 기준 | 직전 RV 지속성, EWMA, HAR-RV, 동일 피처 Ridge | 같은 의사결정 시각·평가 표본·양수 분산 예측 |
| +만기 | 실제 잔존시간·요일·만기군 | 기간·만기 구간별 오차 감소 여부 |
| +유동성/거래량 | 상대 스프레드·잔량 불균형·거래량 | 동시 관측 시각과 stale 필터 통과 |
| +OI | 계약별 변화와 만기/머니니스 버킷 집계 | 발표지연·롤·분모 0 처리 후 추가 정보 |
| +IV/스마일 | 검증된 단위의 IV·스큐·기간구조 | 유효한 동시 호가와 만기 커버리지 |
| 비선형 확장 | LightGBM | 단순모형 대비 시간 외 표본에서 안정적 개선 |

GARCH는 수익률 기반 조건부 분산 비교군으로 포함할 수 있다. Isolation Forest는 데이터 오류와 시장 이상을 구분하는 보조 점수이며 바로 위험 확률로 쓰지 않는다. Ridge stacking은 훈련 내부의 순수 OOF 예측으로만 적합하고 단독 모형 대비 개선할 때 채택한다. SHAP/LLM 설명은 검증된 입력·모델 결과·출처를 서술하는 마지막 단계다.

검증은 확장 또는 이동 훈련창의 시간 순 분할로 수행한다. 같은 날짜·만기에 속한 여러 계약은 같은 fold에 둔다. 훈련 라벨 종료가 검증 시작과 겹치는 행은 제거하고, 변환·임계값·국면·하이퍼파라미터는 훈련에서만 결정한다. 마지막 독립 기간은 모형 선택 후 한 번 평가한다. 1,258개 계약/세션 행은 1,258개의 독립 만기 사건이 아니다.

회귀 주 지표는 양수 예측에 대한 QLIKE(`log(pred)+actual/pred`)와 log-RV MAE, 보조로 만기·국면별 오차를 사용한다. 0 RV의 로그 처리 규칙은 훈련에서 고정하고 제외율을 보고한다. 분류는 PR-AUC/Brier/보정, 경보는 고정 경보 예산의 정밀도·지연을 평가한다. 날짜/만기 블록 신뢰구간, 공통 표본의 ablation, 독립 거래일·만기 수를 함께 보고한다. 유의성이나 성능 향상이 없는 결과도 그대로 채택한다.

## 가격곡면과 전이는 두 번째 단계다

상수변동성 해석해와 Monte Carlo를 먼저 맞추고, 상품에 맞는 배당/선도·행사/결제 방식으로 가격을 정의한다. 주식·지수·선물 옵션에 하나의 공식을 무조건 적용하지 않는다. 유효한 복수 행사가·복수 만기 호가가 충분할 때 무차익 제약 IV 곡면을 만들고, 이후 Dupire 로컬변동성을 검토한다. 짧은 만기·희소 곡면에 바로 미분을 적용하지 않는다.

가격모형의 위험중립 분포(Q)와 미래 위험 예측의 실제 확률분포(P)를 구분한다. 호가 범위 위반율, 만기/행사가 외 표본 가격 오차, 비용 포함 델타 헤지오차·꼬리손실을 비교한다. 신호 계산 이후 최초 실행 가능한 bid/ask, 수수료·슬리피지·승수·계약 수 제약을 적용한다. 미드 가격 즉시 체결은 기본 가정으로 사용하지 않는다.

해외·지수→개별주식 전이는 국내 단독 기준과 비교하고 대상 시장 최종 홀드아웃을 둔다. 기업실적·배당·분할·개별 점프와 거래밀도 차이를 별도 평가한다. 지수 성능을 개별주식 성능으로 대체하지 않는다.

2. **키 설정 후 첫 관문:** 모의 토큰과 scopes/만료, 주간 대표 계약 1개 조회, `Occurs1` 실제 형태, 단위·시각, 2구독 WebSocket을 읽기 전용으로 확인한다. 실전/야간·해외는 각각 권한을 확인한다.
3. **데이터 파일럿:** 원문·수신시각·연속조회·재연결을 보존하고 18구독 범위로 누락률·호가 오류율·세션별 커버리지를 측정한다. 역사 자료의 최초일·만기 코드 조회가 되는지 확인한다.
4. **H5/H6 검증:** 충분한 독립 거래일·만기 사건을 확보한 후 기준모형과 추가 피처를 동일 표본에서 비교한다. 역사 범위가 짧으면 기술통계와 수집 품질 평가까지로 제한한다.
5. **가격·헤지·전이:** 자료와 1차 성능 조건을 통과한 경우에만 확장한다. RFQ/보유집중도는 별도 자료 확보 후 진행한다.

8–12주 파일럿은 수집 체계와 재현성을 만드는 일정 가정이다. 그 기간만으로 통계적 검정력·수익성·도입 인과효과가 보장되지 않는다. 실제 시장 시계열이 없는 이번 PR에는 예측 AUC·수익률·p값을 만들지 않았다.
