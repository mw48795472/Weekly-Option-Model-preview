## 2. 장중 RV와 구분한 결과 변수

주 분산 대용치는 **Parkinson = log(H/L)² / (4 log 2)**입니다. 기초자산의 실제 일별 고가·저가를 사용하며 장중 분봉 수익률 제곱합 RV가 아닙니다. 연율화하지 않은 일별 분산입니다. 그림에만 sqrt(Parkinson)×100을 표시합니다. 이 추정량에는 확산과 연속 관측 같은 가정이 있고 overnight 점프·장중 순서·마감 30분 움직임을 복원하지 못합니다.

보조 예측 결과는 **종가 로그수익률 제곱**입니다. 두 분산 대용치의 QLIKE 절대 수준은 직접 비교하지 않습니다. 기획서의 장중 RV·REV를 완성하려면 실제 시각별 기초가격이 추가로 필요합니다. TWSE는 [과거 5초 지수 상품](https://eshop.twse.com.tw/en/product/detail/b36944ac1b794fcfaf21868b39fc517d)을 별도로 제공하며 구독·활용 범위 확인이 필요합니다.

## 3. H5: 만기 전후의 조건부 차이

종속변수 log(Parkinson)에 위클리 만기 당일·직전·직후 거래일, 월물 만기, 요일, 금요일 위클리 도입기간, 직전 1·5·22일 대용치 성분을 넣었습니다. 표본 단위는 현물 거래일이며 옵션 행사가를 반복 표본으로 세지 않습니다. 주 사양의 rank는 **13/13**입니다.

| 주 사양 · HAC lag 5 | 계수 | 95% 구간 | 해석 |
|---|---:|---:|---|
| 만기 당일 | +0.2797 | [−0.0994, +0.6587] | 양의 점추정이나 0을 포함 |
| 직전 거래일 | +0.0119 | [−0.2697, +0.2935] | 상승 근거 부족 |
| 직후 거래일 | −0.0196 | [−0.2881, +0.2489] | 감소·상승 어느 쪽도 확정 곤란 |

요일×도입기간을 추가하면 당일 계수 +0.2068, 구간 [−0.3093, +0.7230]입니다. 월물 만기를 제외한 계수 +0.2940도 0을 포함합니다. HAC lag 20과 2세션 이동 위약 달력도 함께 저장했습니다. 이들을 독립적인 다수의 검증 성공으로 세지 않습니다. HAC 구간은 점근 정규 근사입니다.

![H5 계수와 H6 추가 예측력 구간](images/empirical/h5_h6_evidence.png)

**full rank는 인과 식별의 증명이 아닙니다.** 회귀 표본에서 월요일 위클리 만기는 6일, 화요일은 2일뿐입니다. 수요일 비위클리만기에는 월물만기가 포함되고 금요일 제도기간도 다릅니다. 휴일 이동을 외생적 도구변수로 간주하지 않았습니다.

예정 만기와 실제 결제일은 **202607F2 한 건에서 2026-07-10 대 2026-07-13**으로 달랐습니다. 원래 예정일을 덮어 숨기지 않고 [감사 CSV](../data/analysis/empirical/expiry_schedule_audit.csv)를 남겼습니다. 회귀는 실제 결제일을 쓰며, 예측 달력도 사후 확정 달력입니다. 당시 일정·정정 공지의 판본과 알려진 시각은 복원하지 못했습니다.

## 4. H6: OI의 추가 예측 가치를 시간순으로 검증

주 피처는 두 시점 모두 존재한 계약들의 합계에 대해 **(OI_t−OI_t−5)/OI_t−5**를 계산합니다. 전기 합계가 0이면 정의하지 않습니다. 새로 관측된 계약·사라진 계약 OI와 전체 체인의 변화율은 별도 열에 남깁니다.

이 방식은 롤오버를 분리하지만 계속 존재한 계약이 차지하는 전기 OI의 중앙값이 **4.1%**에 불과합니다. 주 피처 39일은 최초 5일 워밍업 또는 전기분모 0으로 결측입니다. 지연 피처·과거 변동성·미래 라벨을 모두 만족한 공통 날짜만 모델별로 동일하게 사용합니다. 따라서 결과는 해당 가용 표본에서의 제한된 비교입니다.

주 시나리오는 OI 1거래일 지연, 민감도는 2거래일 지연입니다. 의사결정일 t의 기초지수 종가를 반영하고 t−1 또는 t−2 OI를 안다고 가정했습니다. 공표·수신·정정 시각이 없으므로 지연을 넣었다는 이유만으로 시점 가용성이 검증된 것은 아닙니다.

**타깃은 다음 5거래일 대용치의 평균**입니다. 마지막 5일은 미완결로 남깁니다. 훈련 라벨의 종료일이 테스트 예측일보다 엄격히 이전이어야 합니다. 최소 100개 완결 라벨에서 시작해 확장창 OLS를 수행하며, 로그 예측은 훈련 잔차의 Duan smearing으로 양의 분산 평균으로 환산합니다. 파라미터·피처 튜닝 없이 고정된 비교를 실행했습니다.

HAR은 여기서 장중 RV가 아닌 대용치의 일·주·월 성분을 쓰는 **HAR 형태 기준모형**입니다. 기준→달력→OI 순서로 정보의 추가 가치를 비교합니다.

| Parkinson 주 결과 | QLIKE | MAE | 비교 |
|---|---:|---:|---|
| 직전 상태 지속 | −7.79383 | 0.00008910 | 단순 기준 |
| HAR 형태 기준 | −8.08072 | 0.00006262 | 일·주·월 성분 |
| HAR + 달력 | −8.07650 | 0.00006203 | 다음 5일 만기 수·제도기간 |
| + 동일 계약 OI 1일 지연 | −8.07489 | 0.00006148 | 주 H6 |
| + 동일 계약 OI 2일 지연 | −8.07514 | 0.00006135 | 시각 가정 민감도 |
| + 전체 체인 OI 1일 지연 | −8.07606 | 0.00006206 | 롤오버 민감도 |

정확한 수치는 [점수 CSV](../data/analysis/empirical/h6_scores.csv)에 있습니다. QLIKE = log(f)+y/f는 낮을수록 좋고 음수가 정상일 수 있습니다. 손실 차이를 퍼센트 수익률처럼 해석하지 않습니다.

**주 H6 손실차(OI 추가−달력 기준)는 +0.00160, 10거래일 블록 부트스트랩 95% 구간 [−0.00401, +0.00667]입니다.** 점추정은 소폭 악화 방향이나 유의한 개선·악화 어느 쪽도 확정하지 못합니다. 블록 길이 5·10·20, 2,000회, seed 4879를 사용하며 테스트 날짜가 빠진 거래일도 빈칸으로 보존해 블록을 구성합니다. 겹치는 5일 미래 라벨을 독립 관측으로 검정하지 않습니다. 종가 수익률 제곱 민감도에서도 OI 추가의 개선을 확인하지 못했습니다.

![H6 시간순 누적 손실차](images/empirical/h6_cumulative_loss.png)

선이 내려가면 그 기간 OI 모형이 달력 기준보다 손실을 덜 냈고, 올라가면 더 냈습니다. 2일 지연의 일부 구간 개선이 뒤집히는 모습은 구간 선택의 위험을 보여줍니다. 전체 기간 신뢰구간과 함께 판단해야 합니다. 이 결과는 OI가 언제나 무용하다는 증거가 아니며, 새로운 피처를 결과에 맞춰 선택할 근거도 아닙니다.

## 5. 홍콩 HKEX: 접근 가능성과 활용 가능성을 구분

공식 위클리 HSI 일별 보고서 접근 및 1개 샘플의 필드·합계 검증을 완료했습니다. HSI 지수옵션 보고서이며 개별주식 옵션의 원장은 아닙니다.

| 확인 항목 | 구조·주의 |
|---|---|
| 계약키 | HSI 위클리 + 실제 만기일 + 콜풋 + 행사가; 주문 코드와 별도 |
| 가격 | 주간 open·high·low, OQP, 야간 close; **OQP는 공식 호가가격이며 체결 종가 아님** |
| 거래량 | 주간·야간을 따로 두고 결합 거래량과 합계 대사 |
| 포지션 | 결합 OI·OI 변화; 주간과 야간에 같은 OI를 두 번 더하지 않음 |
| 기초자산 | HSI 현물 역사 OHLC·장중가격 미확보; 옵션 OQP를 현물 가격으로 쓰지 않음 |
| 개별주식 | 기존 해외 보고서의 [54개 클래스 명부](research/overseas-data/README.md)를 유지; 이번 HSI 수집과 구분 |

[HKEX 이용약관 5절](https://www.hkex.com.hk/Global/Exchange/Terms-of-Use?sc_lang=en)에서 자동 접근, 파생 데이터베이스 작성 및 제3자 공개에 별도 허락이 필요함을 확인한 뒤 추가 자동 수집과 홍콩 모형 분석을 중단했습니다. **사용자는 별도 데이터 권한이 없으므로 공개 저장소·ZIP·Streamlit에 HKEX 시세·원문·파생 시계열을 넣지 않았습니다.** 로컬 캐시는 git 제외 영역에 있으며 공개 수집기에서는 HKEX 경로를 제거했습니다. 파서 테스트는 실제 시세를 복사하지 않은 합성 예시입니다.

[공식 일별 보고서](https://www.hkex.com.hk/Market-Data/Statistics/Derivatives-Market/Daily-Market-Report-(Latest)?sc_lang=en)와 [Data Marketplace](https://data.hkex.com.hk/)를 기준으로 다음을 확인해야 합니다: 자동 조회, 연구/모형 학습, 파생 통계 공개, 공개 Streamlit 표시, GitHub 원자료 배포, HSI 및 개별주식 위클리의 역사 계약 범위. 현재 **홍콩 H5/H6 검증은 보류**입니다.
