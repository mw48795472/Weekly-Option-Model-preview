# H5·H6 실측 확장 분석 규칙

결과 계산 전 고정한 규칙(2026-10-12). 기존 합성 실험과 구분한다.

- 모집단: TAIFEX TXO 정규장 전체 위클리 계약, 2025-01-01–2026-10-08. 단위는 TAIEX × 거래일이다. 개별주식 H5/H6나 국내 전이 검증으로 확장 해석하지 않는다.
- 기초가격: TWSE 공식 TAIEX 일별 OHLC. 주 결과는 Parkinson 일중 범위 분산 log(H/L)^2/(4 log 2). 장중 RV가 아니며 overnight 움직임을 포함하지 않는다. 종가 로그수익률 제곱을 예측 민감도로 병기한다.
- H5: 실제 최종결제일을 매 거래일에 결합한다. weekly expiry, 직전·직후 세션, 월물 만기, 요일, 금요일 위클리 도입 이후, 과거 1·5·22일 범위분산을 포함한 설명적 OLS. HAC 5·20 lag, rank, 요일별 대조 관측을 공개한다. 요일×도입기간, 월물만기 제외, 2세션 이동 위약 달력은 진단이며 다중 검정의 독립 성공으로 세지 않는다. 사후 결제일 달력에는 당시 일정 판본이 없다는 한계가 있다.
- H6: 주 피처는 t와 t−5 모두 존재한 동일 계약들의 OI 합계 변화율(전기분모). 전체 체인 변화율은 롤오버 민감도다. 신규·소멸 OI를 따로 저장한다. 주 시나리오는 OI 1거래일 지연, 보조는 2일 지연. 공표시각이 확인된 운영 백테스트라는 의미는 아니다.
- 타깃: 다음 5거래일 주 분산 대용치의 평균. 끝 5개 라벨은 결측. 주모형은 persistence → HAR 형태(1·5·22일 log 대용치) → 달력 추가 → OI 추가. 로그 회귀의 예측을 훈련 잔차 smearing으로 양의 분산 평균으로 환산한다.
- 확장창, 최소 100개 완결 훈련 라벨. 훈련 라벨의 종료일은 테스트 의사결정일보다 엄격히 이전이어야 한다. 모델과 지연 시나리오 모두 같은 테스트 날짜를 쓴다. 튜닝이나 최우수 피처 선택을 하지 않는다.
- 주 점수 QLIKE=log(f)+y/f, 보조 MAE·log MSE. OI 모형−달력 모형의 손실차가 음수면 개선이다. 5·10·20일 이동 블록 부트스트랩 2,000회, 고정 seed 4879의 95% 구간. 개별 겹침 라벨을 독립 표본처럼 검정하지 않는다.
- HKEX: 무료 HSI weekly final daily market reports 2026-07-01–2026-10-09. 실제 HTTP/파싱 실패를 기록한다. OQP는 공식 호가가격으로 체결 종가가 아니다. 일중 가격·분리 세션 거래량·결합 OI 합계를 대사한다. 지수 현물 이력 미확보이면 홍콩 H5/H6 성과를 만들지 않는다.

## HKEX 범위 수정: 분석 전 이용조건 확인

공개 보고서 접근 및 1개 샘플의 필드·합계 검증 뒤 [HKEX 이용약관 5절](https://www.hkex.com.hk/Global/Exchange/Terms-of-Use?sc_lang=en)의 자동 접근·파생 DB·제3자 배포 제한을 확인했다. 추가 자동 수집과 홍콩 모형 분석을 중단하고 네트워크 수집 코드에서 HKEX 경로를 제거했다. 사용자에게 별도 권한이 없으므로 응답 캐시는 git 제외 영역에 두고 공개 산출물에 원문·시세·파생 시계열을 포함하지 않는다. 대시보드에는 데이터 구조·권한 상태·공식 링크를 기재한다. 향후 허용된 파일을 받은 뒤 정규화 파서를 사용할 수 있다.
