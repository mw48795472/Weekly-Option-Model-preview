# 기존 Weekly Option 자료 감사

폴더의 연구 자료 **21개**(DOCX 4, PDF 5, Python 5, PNG 6, ZIP 1)를 검토한 내용을 API 명세에 연결했다. Office의 `~$` 임시 잠금 파일은 연구 자료에서 제외한다. 파일명·크기·SHA-256과 ZIP의 중복 관계는 [원천 목록](../data/analysis/weekly_option_source_inventory.json)에 있다. 개인 문서 원본과 연락처는 이 저장소에 복사하지 않았다.

## 코드에서 확인된 전환 전 수정 사항

| 원본 코드·위치 | 문제와 영향 | 새 설계에서의 처리 |
|---|---|---|
| `h5_h6_hypothesis_test.py` L25–38 | 생성식에 만기 효과를 주입, 목요일 고정, 일 절대수익률을 변동성으로 사용 | 결과는 합성 시연. 실제 만기 캘린더와 장중 제곱 로그수익률 합으로 재정의 |
| 같은 파일 L48–72 | OI 변화율 분모가 전기 OI가 아닌 현재 OI | `oi_change`는 전기 분모 사용, 0/결측 분리. 동일 계약·공표시각을 별도 검사 |
| `h7_concentration_sensitivity.py` L29–66 | 4개 집중도 상수와 민감도의 관계를 생성식에 주입 | 시변 보유/집중도 자료 확보 전 원 가설 보류 |
| `h9_rfq_cqbreak_enhanced.py` L87–124 | 주석의 미래 5분과 실제 t+4…t+8 창 불일치, 마지막 미래 결측을 0으로 분류, 시간 분할 gap 없음 | `forward_mean`은 t+1…t+h, 미완성 라벨은 결측. `purged_training_indices`로 중첩 라벨 제외 |
| 같은 H9 코드 | 합성 RFQ/CQ와 스프레드 라벨을 방향 신호로 해석 | RFQ 가설은 전용 로그 필요. H9b는 장내 유동성 예측으로 분리 |
| `expiry_reversal_analysis.py` L31–117 | 그룹별 반전 효과를 생성, 전체 표본 중위수와 다중 비교 사용 | 실제 사건·비교일·공표시각, 사전 지정 주 검정과 날짜 블록 추론 |
| `로컬변동성 모형 수치해석 기초 코딩.py` L51, L158–198, L297–396 | 실제는 상수 σ GBM/MC. Dupire·시장 곡면 보정 없음. 종목 열순서 재명명, 고정 평가일/가상 계약 | GBM 수치 기준으로 분류. ticker 매핑, 실제 계약·배당·승수·단위·Q/P 구분 후 가격 검증 |

새 함수는 위 결함 중 수식·시간 정렬의 최소 규약을 테스트하기 위한 것이다. 기존 스크립트 전체를 실측용으로 고쳤거나 자동 매매 모델을 완성했다는 의미는 아니다. 원본 스크립트의 데이터 생성이나 네트워크 다운로드 코드는 실행하지 않았다.

## 재사용과 보류

도표 구성, 가설의 경제적 질문, 비교 모형 목록, 이벤트 분석 틀을 재사용한다. 합성 상관·p값·AUC를 시장 실증으로 옮기지 않는다. OI·호가만으로 투자자 포지션 부호, 보유 집중도, RFQ 또는 리밸런싱을 확정하지 않는다. 데이터 생성 부분만 NH 로딩으로 바꾸는 접근은 만기·휴일·결측·동시 관측·공표 지연을 처리하지 못하므로 별도 어댑터와 검증 계층이 필요하다.
