# 수행 결과와 검증 한계

검사일: 2026-10-11 KST. 키 미설정 상태에서 문서·공개 자료·오프라인 검증을 수행했다.

| 항목 | 관측 결과 | 해석 |
|---|---|---|

| 공개 국내 마스터 | 3개, 총 25,744행 | 전체 26필드 파싱, 각 파일의 세션/series 중복 0 |
| 지수 위클리 후보 | 1,258행 / 고유 series 766 | 이름 기반 후보. 활성·시세 권한 미검증 |
| 오프라인 테스트 | 21개 통과 | 계약 구성, 자료 무결성, 연구 수식/라벨 검증 |

무인증 네트워크 검사는 01:58 KST경 포털 1회, 실전·모의 시세 각각 1회에 한정했다. 시세 요청의 `sym=A016C000`은 공개 마스터에서 관측한 코드다. `Authorization`은 보내지 않았고 토큰·주문·잔고 endpoint는 호출하지 않았다. 원시 판정 근거는 [접근 점검 JSON](../data/analysis/public_access_probe.json)에 UTC 시각·HTTP status와 함께 저장했다. 401만으로 계약 유효성이나 계정 권한을 확인할 수 없다.

실행 환경에서 최초 네트워크 검사는 시스템 TLS 설정 접근, 최초 테스트는 임시 폴더 쓰기 권한에 의해 중단됐다. 승인된 재실행으로 각각 응답 확인·21개 테스트 통과를 완료했다. TLS 인증서 검증은 끄지 않았다.

## 테스트가 보장하는 범위

- form 인증의 예약문자 인코딩, demo/live 주소 분리, 출력에서 키·토큰 값 제외.
- 허용된 시세 요청만 구성, 주문·계좌 잔고 차단, 필수/미지/잘못된 타입 필드 확인.
- 분봉 기본값·1분 명시·9,999건 한도·야간 모의 차단.
- WebSocket 키 GET·세션 초기화·pingpong/구독/데이터 구분·계좌 총 20구독 계획.
- 0/결측·비정상 숫자·역전 호가, 차트 배열과 nrec 일치.
- OI의 전기 분모, 정확한 미래 창, 미완성 라벨 유지, 평가 시작을 넘는 훈련 라벨 제거.
- API 원본 해시, 49개 명세 대응과 필드 일치, 공개 마스터 요약 재계산.

요청 구성기의 필드 검사와 구독 계획은 **운영 수집기 전체가 아니다**. 실제 발급/연결, 토큰 보관·갱신, 한도 스케줄러, 자동 연속조회, 재접속/복구, 서버 오류 해석은 아직 구현·검증하지 않았다. 저장된 응답 예제도 실측 시세 fixture가 아니다.

## 키 설정 후 남은 읽기 전용 확인

| 관문 | 확인 내용 | 통과 결과로 남길 것 |
|---|---|---|
| 인증 | 모의 키 발급·scopes·유효기간 | 비밀값을 제거한 상태/만료/환경 기록 |
| 대표 계약 | 최신 마스터와 현재가의 코드·만기·가격 비교 | 계약 매핑, 단위·0/결측 규칙 |
| 차트 | 실제 Occurs1 형태, nrec, cursor, 최초일, 만기 계약 | 마스킹 fixture·페이지 종료 규칙·이력 범위 |
| 체인 | 위클리 만기의 prd/exp_mon 조회·모든 행사가 | 페이지 완결성·주간/야간 스키마 차이 |
| 실시간 | 2개 구독으로 init·ack·pingpong·이벤트·해제 | 시각·sequence·제어 메시지 표본 |
| 품질 | OI 공표/갱신·IV 단위·세션 전환·자료 신선도 | available_at 규칙·제외율·결측구간 |
| 별도 권한 | 실전 야간/해외 이용, IP 조건·비용·저장 범위 | 공식 계정 설정과 사용 조건 |

이 관문 전에는 실제 AUC·QLIKE·p값·헤지 수익을 계산할 시장 시계열이 없다. 이번 수치 결과는 API 문서 감사와 공개 마스터 기술통계에 한정한다.

## 재현 가능한 산출물

`scripts/build_catalog.py`는 원본 Excel을 다시 읽어 필드 카탈로그·해시·차이·색인을 만든다. `scripts/analyze_masters.py`는 저장한 원본 gzip에서 후보 CSV와 통계를 재생성한다. `scripts/inventory_sources.py`는 사용자가 지정한 연구 폴더의 파일 해시와 ZIP 중복을 기록하며 원본을 복사하지 않는다. GitHub workflow는 네트워크 시세 검사를 실행하지 않고 이 두 생성기와 오프라인 테스트, 생성물 차이를 검사하도록 구성했다.
